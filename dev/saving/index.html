Saving the results

The results of a fit are saved for long term preservation and further analysis. The posterior samples, the best fit spectra as histograms in LH5 files, and the values of the parameters with their uncertainty in a YAML file. The tutorial shows all of them for a complete fit.

Posterior samples

The samples are saved by BAT.jl, which writes them to an HDF5 file with bat_write and reads them back with bat_read. The package HDF5 has to be loaded:

using BAT, HDF5

bat_write("samples.h5", samples)
samples = bat_read("samples.h5").result

The file has one dataset for each quantity, with one entry for each sample:

v/<name>        value of each parameter (here the activities)
weight          number of times the sample was repeated by the sampler
logd            logarithm of the posterior density at the sample
info/chainid    chain, walker, step number and other bookkeeping of the sampler

Best fit spectra

get_best_fit_histograms makes a histogram of the prediction of the model for the parameters, usually the best fit. The result is a dictionary with the total in the key :total and the contribution of each source, with the name of its activity. The bins outside the fit range and in the blinded region are empty.

hists = get_best_fit_histograms(best, model, bin_edges)

write_best_fit writes them to an LH5 file, with the total in best_fit/total and each source in best_fit/<name>. With data the measured spectrum in the same bins is saved too, in data. All can be read back with read_hist.

file = joinpath(outdir, "best_fit.lh5")

counts = get_counts(data, bin_edges)
write_best_fit(file, hists; data = counts_to_histogram(counts, bin_edges))

read_hist("best_fit/K40_hpge_bulk", file)

Parameter values

write_parameter_values writes the values of the parameters, here the activities, to a YAML file. For each parameter it saves the best fit and an interval, and the file records the credible level of the intervals. The intervals are the smallest credible intervals: the shortest intervals that contain 68% of the posterior. BAT.jl computes them, and mode = :connected gives one interval for each parameter:

using Statistics

best = mode(samples)
intervals = map(first, BAT.smallest_credible_intervals(samples; p = 0.68, mode = :connected))
Note

BAT.jl marks smallest_credible_intervals as internal, so it may change between versions.

Here the intervals are made up:

using IntervalSets

file = joinpath(outdir, "parameters.yaml")

intervals = map(a -> 0.9a .. 1.1a, best)
write_parameter_values(file, best, intervals; level = 0.68)

print(read(file, String))
