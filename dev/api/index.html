Refit.build_forward_model — Method
build_forward_model(pdfs; e_low, e_high, blind, norm, binning)

Build a function that maps fit parameters to the predicted counts per energy bin.

pdfs is a dictionary Dict(name => Histogram) of simulated 1D energy spectra that all share the same binning. Energies are in keV. Only bins fully inside [e_low, e_high] and outside the blind = (min, max) region are kept. binning merges that many consecutive bins first.

Returns (forward_model, bin_edges):

  • bin_edges: (low, high), the lower and upper edges in keV of the kept bins
  • forward_model(params): predicted counts per kept bin for params = (activities = (name1 = a1, name2 = a2, ...),), with one activity per spectrum, in any order. Each spectrum is scaled by activity * norm. Use norm for unit conversions and the livetime. Each call allocates one array.

The loop over spectra is unrolled at compile time, which only works for about 30 spectra or fewer. With more, each call makes extra small allocations and is slower.

Refit.build_likelihood — Method
build_likelihood(counts, model)

Build the Poisson log-likelihood of the measured counts as a function of the parameters of model.

counts is a flat vector with one entry per bin, in the same order as the output of model(params). Get it from a histogram with get_counts, so that the bins are the ones the model predicts. model comes from build_forward_model.

Returns a log-density function: evaluate it with DensityInterface.logdensityof(likelihood, params).

Refit.counts_to_histogram — Method
counts_to_histogram(counts, bin_edges)

Turn a flat vector of counts back into a Histogram, for example to plot the model prediction. This is the inverse of get_counts.

counts[i] is the content of the bin between bin_edges.low[i] and bin_edges.high[i]. The bins must be sorted and must not overlap. The histogram covers the range from low[1] to high[end]. A gap between two bins, such as a blinded region, becomes one bin with 0 counts.

Refit.get_counts — Method
get_counts(data::Histogram, bin_edges)

Measured counts in the bins of the forward model, as a flat Vector{Float64}.

bin_edges = (low = ..., high = ...) are the lower and upper edges of the bins, for example the ones returned by build_forward_model. The result is not a histogram: it has one entry per bin, in the same order as bin_edges. Each entry is the sum of the data bins between low[i] and high[i], which must be edges of data.

Refit.get_max_norm — Method
get_max_norm(low, high, data, pdf; blind = nothing)

Largest factor by which the simulated spectrum pdf can be scaled without exceeding the measured spectrum data: the ratio of the counts of data and pdf between low and high (keV). Only bins fully inside that range and outside the blind range (min, max) are used. data and pdf must have the same binning.

Returns Inf if pdf has no counts in the range.

Refit.get_priors — Method
get_priors(pdfs, data; ref_ranges, e_low, e_high, blind, norm,
           range_factor, peak_factor)

Estimate a range 0 .. a_max for the activity of each simulated spectrum in pdfs (a Dict(name => Histogram)), based on the measured spectrum data. Returns Dict(name => Interval).

These are not real informative priors. They come from the data and only limit the range of the fit to improve convergence. We can also use external knowledge for informative priors.

a_max is the largest activity for which the prediction stays below the data, in a window: a safety factor times get_max_norm divided by norm. It is the smaller of two values:

  • the value in the fit range [e_low, e_high], times range_factor (default 1.1),
  • the value in the reference range of the source, times peak_factor (default 1.5).

ref_ranges is a Dict(key => (low, high)) with energy ranges in keV, for example around a peak. A spectrum uses the range of the longest key that its name starts with, for example :K40_hpge_bulk uses :K40. Spectra without a range only use the fit range. e_low, e_high, blind and norm are as in build_forward_model.

Refit.poisson_likelihood — Method
poisson_likelihood(obs, pred)

Poisson log-likelihood of observed counts obs given predicted counts pred, dropping the constant -log(k!) term. pred must be positive; a tiny eps() is added to avoid log(0).
