Refit.build_forward_model — Method
build_forward_model(components; e_low, e_high, blind, norm, binning, edges, points_per_bin)

Build a function that maps fit parameters to the predicted counts per energy bin.

components is a dictionary Dict(name => component). Each component is one of:

  • a Histogram, a simulated 1D energy spectrum in keV: its activity is the fit parameter with the same name, params[name]
  • (pdf = histogram, activity = f): its activity is f(params), a function of the fit parameters. For example to fit a half-life instead of an activity, or to tie the activities of two components together
  • (pdf = histogram, analytic = g), also with activity = f: the simulated spectrum is multiplied in every bin by g(E, params), a function of the energy E in keV. For example an efficiency curve, or the factor $(Q - E)^2$ of a beta decay
  • (analytic = g,): an analytic spectrum with no simulation, for example a flat background. g(E, params) is the expected number of counts per keV at the energy E

params is the named tuple of all fit parameters, in any order. The prediction of a component in bin i is activity * norm * g(E_i, params) * counts[i], with g = 1 without analytic, and g(E_i, params) * width_i for an analytic component with no simulation. E_i is the energy at the centre of the bin and width_i its width in keV. The model is the sum over the components. Use the global norm for unit conversions and the livetime: it multiplies every component with a histogram, so an activity function returns an activity in the same units as a fit parameter. It does not multiply an analytic component with no simulation. By default g is evaluated at the bin centre only, which is inaccurate for features narrower than about one bin, such as peaks. With points_per_bin = n, the bin is split into n equal parts, g is evaluated at the centre of each and the n values are averaged. This takes n times as many calls of g, and the error of the integral over the bin falls as $1/n^2$.

All histograms must share the same binning. Without any (only analytic components), give the bin edges in keV with edges. Only bins fully inside [e_low, e_high] and outside the blind = (min, max) region are kept. binning merges that many consecutive bins first.

Returns (forward_model, bin_edges):

  • bin_edges: (low, high), the lower and upper edges in keV of the kept bins
  • forward_model(params): predicted counts per kept bin
  • forward_model(params, Val(:by_component)): a named tuple with the predicted counts of each component, in the order of the sorted names

The time per call grows with the number of bins times the number of components. An activity function adds about 0.1 microseconds per call, an analytic function a call of the function in every bin.

Refit.build_likelihood — Method
build_likelihood(counts, model)

Build the Poisson log-likelihood of the measured counts as a function of the parameters of model.

counts is a flat vector with one entry per bin, in the same order as the output of model(params). Get it from a histogram with get_counts, so that the bins are the ones the model predicts. model comes from build_forward_model.

Returns a log-density function: evaluate it with DensityInterface.logdensityof(likelihood, params).

Refit.build_prior_dist — Method
build_prior_dist(ranges)

Build a prior distribution from the entries of get_priors, a Dict(name => prior). Each prior is either a range (Interval), which becomes a uniform distribution, or any 1D distribution from Distributions.jl, which is used as is. It is a NamedTupleDist (from ValueShapes.jl) and rand(prior) draws a named tuple of activities, which can be passed to the forward model.

Refit.counts_to_histogram — Method
counts_to_histogram(counts, bin_edges)

Turn a flat vector of counts back into a Histogram, for example to plot the model prediction. This is the inverse of get_counts.

counts[i] is the content of the bin between bin_edges.low[i] and bin_edges.high[i]. The bins must be sorted and must not overlap. The histogram covers the range from low[1] to high[end]. A gap between two bins, such as a blinded region, becomes one bin with 0 counts.

Refit.fit_axes — Method
fit_axes(; scale = :log, title = "", ylabel = "Counts", size = (1300, 600), colors)

Make a CairoMakie figure for the plot of a fit: an axis for the spectra with an axis for the residuals below it. The energy axes are linked and only the lower one has labels. Returns (fig, ax, ax_residuals).

size is the size of the figure in pixels. With scale = :log the y axis of ax is logarithmic, with :linear it is linear. The lines drawn by plot_hist! without a color take the next of colors, a vector of colors that repeats after the last one. The default is a color-blind friendly palette of 7 colors.

Draw on the axes with plot_hist!, mark_blinded! and plot_residuals!, and set the limits, for example with CairoMakie.xlims!(ax, 100, 4000).

Refit.get_best_fit_histograms — Method
get_best_fit_histograms(parameters, model, bin_edges)

Histograms of the prediction of the model for the parameters (a named tuple, for example the best fit). model and bin_edges come from build_forward_model.

Returns an ordered dictionary name => Histogram with the total prediction in :total, followed by the contribution of each component under its name in the model, sorted by name. The blinded region and the range outside of the fit are empty bins (see counts_to_histogram).

Refit.get_counts — Method
get_counts(data::Histogram, bin_edges)

Measured counts in the bins of the forward model, as a flat Vector{Float64}.

bin_edges = (low = ..., high = ...) are the lower and upper edges of the bins, for example the ones returned by build_forward_model. The result is not a histogram: it has one entry per bin, in the same order as bin_edges. Each entry is the sum of the data bins between low[i] and high[i], which must be edges of data.

Refit.get_max_norm — Method
get_max_norm(low, high, data, pdf; blind = nothing)

Largest factor by which the simulated spectrum pdf can be scaled without exceeding the measured spectrum data: the ratio of the counts of data and pdf between low and high (keV). Only bins fully inside that range and outside the blind range (min, max) are used. data and pdf must have the same binning.

Returns Inf if pdf has no counts in the range.

Refit.get_priors — Method
get_priors(pdfs, data; ref_ranges, e_low, e_high, blind, norm,
           range_factor, peak_factor)

Estimate a range 0 .. a_max for the activity of each simulated spectrum in pdfs (a Dict(name => component), see build_forward_model), based on the measured spectrum data. Components with an activity or an analytic function are skipped: the parameters of the function need priors by hand. Returns Dict(name => Interval). The entries can be replaced by any 1D distribution from Distributions.jl before calling build_prior_dist.

These are not real informative priors. They come from the data and only limit the range of the fit to improve convergence. We can also use external knowledge for informative priors.

a_max is the largest activity for which the prediction stays below the data, in a window: a safety factor times get_max_norm divided by norm. It is the smaller of two values:

  • the value in the fit range [e_low, e_high], times range_factor (default 1.1),
  • the value in the reference range of the source, times peak_factor (default 1.5).

ref_ranges is a Dict(key => (low, high)) with energy ranges in keV, for example around a peak. A spectrum uses the range of the longest key that its name starts with, for example :K40_hpge_bulk uses :K40. Spectra without a range only use the fit range. e_low, e_high, blind and norm are as in build_forward_model.

Refit.group_histograms — Method
group_histograms(hists, groups)

Sum the sources of the best fit into groups, for example to plot fewer lines. hists is the result of get_best_fit_histograms and groups is a vector with one label => selection for each group. The selection is one of

  • a vector of source names, for example [:K40_cables, :K40_fibers],
  • a regular expression that is matched to the source names, for example r"K40",
  • :rest, for all the sources that no other group selects.

Returns an ordered dictionary in the same format as hists, with :total followed by the groups, which are named by their label as a Symbol. The label can be any text, including Unicode such as "²¹²Pb" or "2νββ". A source goes into the first group that selects it, and a group without sources is left out. A name that does not exist, or a regular expression that matches no source, is an error.

grouped = group_histograms(
    hists,
    ["K40" => r"K40", "Pb212" => [:Pb212_cables], "other" => :rest],
)

Refit.mark_blinded! — Method
mark_blinded!(ax, h; kwargs...)

Mark the empty bins of the Histogram h on the CairoMakie axis ax with a vertical band. These are the bins that are not fitted, for example the blinded region in the histograms of get_best_fit_histograms. The keyword arguments, for example color, go to CairoMakie.vspan!, and the default is a grey band.

Refit.normalised_poisson_residual — Method
normalised_poisson_residual(mu, obs)

Residual of the observed counts obs with respect to the predicted counts mu, in units of standard deviations. Takes two numbers and returns a Float64, or two arrays of the same size and returns a Vector{Float64}.

For mu >= 50 the Poisson distribution is close to a Gaussian and the residual is (obs - mu) / sqrt(mu). For smaller mu it is the p-value of obs (the probability of at least obs counts above the mode, or of at most obs counts below it), converted into the number of standard deviations of a Gaussian. The sign is positive for an excess of data. A bin with obs < 1 and a prediction below 1 has residual 0.

Refit.plot_hist! — Method
plot_hist!(ax, h; filled = false, kwargs...)

Draw the Histogram h as a step histogram on the CairoMakie axis ax: a line (with linewidth = 2 unless set), or a filled area with filled = true. The other keyword arguments, for example color, linewidth or label, go to the CairoMakie function that draws it (lines! or band!). Empty bins are drawn at 0, or at a very small value on a logarithmic axis. Returns the plot object.

Refit.plot_posterior! — Method
plot_posterior!(ax, samples, name; level = 0.68, nbins = 50, best = nothing,
                truth = nothing, kwargs...)

Draw the marginal posterior distribution of the parameter name on the CairoMakie axis ax, as a step histogram normalised to an integral of 1. samples are the samples of the posterior, for example from bat_sample: the parameters of each sample are in samples.v and its weight in samples.weight. The histogram has nbins bins between the smallest and the largest value.

The bins inside the smallest interval that contains the fraction level of the distribution are filled. This is the same interval as the one saved by write_parameter_values when it comes from BAT.smallest_credible_intervals. The filled region has the color of the histogram with some transparency, or bandcolor, for example bandcolor = :lightblue. With best (for example mode(samples)[name]) a dashed vertical line marks the best fit, and with truth a red line marks the true value. The lower limit of the y axis is 0. The other keywords, for example color or label, go to plot_hist!.

The plots have labels, so a legend can be added with CairoMakie.axislegend(ax), or in another place with CairoMakie.Legend(fig[2, 4], ax).

Returns the interval as low .. high.

Refit.plot_residuals! — Method
plot_residuals!(ax, prediction, data; bands = true, kwargs...)

Draw the residuals of the data with respect to the prediction (both Histograms with the same bins) as points on the CairoMakie axis ax, in units of standard deviations, see normalised_poisson_residual. Bins where the prediction is empty are not fitted and are left out. With bands = true the bands of 1, 2 and 3 standard deviations are drawn behind the points. The keyword arguments, for example color or markersize, go to CairoMakie.scatter!. Returns the plot object.

Refit.read_hist — Method
 read_hist(group, file)

Read a histogram in group group from an lh5 file file and return a Histogram object.

The histogram format is described in the LH5 specification. The group should contain a binning dataset and a weights dataset. Histograms written from Julia (for example by write_best_fit) are read too.

Refit.read_pdf — Method
read_pdf(files::AbstractDict; groups = "pdf/mul_surv", n_prim_field = "nr_sim_events")

Read the same source simulated in several files, for example once per detector type, and return the weighted average of the spectra.

files maps each file name to its weight, for example the mass of the detector type. The weights are divided by their sum. Each file is read with the single-file method, so it is divided by its own number of primaries.

Refit.read_pdf — Method
read_pdf(file; groups = "pdf/mul_surv", weights = nothing, n_prim_field = "nr_sim_events")

Read a simulated spectrum from file, by default as counts per simulated primary.

groups is the name of one group, or a vector of names. The histograms in these groups are multiplied by weights (a vector with one factor per group, by default 1) and summed, then divided by the number of simulated primaries stored in the field n_prim_field. With n_prim_field = nothing the sum is not divided. To scale by anything else, change the weights of the result: h.weights ./= factor.

Refit.write_best_fit — Method
write_best_fit(file, hists; data = nothing)

Write the histograms of get_best_fit_histograms to the lh5 file file: the total in best_fit/total and each source in best_fit/<name>. An existing file is overwritten.

With data (a Histogram, for example from counts_to_histogram) the measured spectrum is also written, in data. The histograms can be read back with read_hist.

source
Refit.write_parameter_values — Method
write_parameter_values(file, parameters, intervals; level = 0.68)

Write the values of the parameters, for example the activities, to the YAML file file. For each parameter it saves the best fit value from parameters and the interval low to high from intervals. Both are named tuples with the same names, and each interval is an Interval.

The intervals should be the smallest credible intervals, the shortest intervals that contain the probability level of the posterior. BAT.jl computes them: map(first, BAT.smallest_credible_intervals(samples; p = 0.68, mode = :connected)). The level is saved in the file as credible_level.
