Running the fit

Refit.jl builds the likelihood and the prior. BAT.jl samples the posterior, which combines the two. The main commands are below, with the model, data and priors of the other examples in this manual:

Sampling the posterior

bat_sample draws samples from the posterior with a Markov chain Monte Carlo (MCMC): nchains chains of nsteps steps each.

using BAT

posterior = PosteriorMeasure(likelihood, prior)
samples = bat_sample(
    posterior,
    TransformedMCMC(proposal = RandomWalk(), nsteps = 10^4, nchains = 4),
).result

A real fit needs more steps, see the tutorials for typical settings. The BAT.jl documentation describes the sampling algorithms, the checks of convergence and the output.

Best fit

The best fit is the global mode of the samples, the sample with the largest posterior density:

best = mode(samples)
(K40_hpge_bulk = 40.07322272223068, Pb212_to_Pb208_hpge_bulk = 10.004037081384782, two_vbb_hpge_bulk = 99.93687873300503)

The mode can also be found without sampling, by maximising the posterior with an optimiser. bat_findmode needs the package Optim for this:

using Optim

best = bat_findmode(posterior, OptimAlg(optalg = Optim.NelderMead())).result

The uncertainty of each parameter, the smallest interval that contains 68% of its posterior, comes from the samples (see Saving the results).
