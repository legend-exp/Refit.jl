Refit.jl

Tools to perform Bayesian (with BAT.jl fits of binned data with models based on Monte-Carlo simulations, often generated with remage.

Refit.jl is a toolkit, it does not provide an end-to-end fitting tool. A fit compares a measured energy spectrum with a sum of simulated spectra. Each simulated spectrum is scaled by the activity. The parameters are found by sampling the posterior, which combines the likelihood of the data with priors.

User manual

Refit.jl can also do a lot more than this, for details see the following pages!

  • Reading histograms: read the data and the simulated spectra and normalise them
  • Forward model: map the activities to the predicted counts in each energy bin
  • Likelihood: compare the predicted counts with the measured ones
  • Priors: estimate ranges for the activities from the data
