Reading simulated spectra

The simulated and data spectra are read from LH5 files (see the LH5 spec). read_hist(group, file) reads one histogram from the group group of file.

The examples below use a small file with two histograms and the number of simulated primaries (nr_sim_events), written here from a test file:

# one raw histogram from the group "pdf/mul_surv"
h = read_hist("pdf/mul_surv", file)

Counts per simulated primary

A simulated spectrum is normally used as counts per simulated primary, so that the activity of the source scales it to the measured counts (see the forward model). read_pdf reads the histogram and divides it by the number of primaries in the field nr_sim_events:

# the default group, divided by the number of primaries
pdf = read_pdf(file)
StatsBase.Histogram{Float64, 1, Tuple{StepRangeLen{Float64, Base.TwicePrecision{Float64}, Base.TwicePrecision{Float64}, Int64}}}
edges:
  0.0:10.0:1000.0
weights: [0.177, 0.214, 0.22, 0.206, 0.212, 0.223, 0.208, 0.214, 0.211, 0.236  …  0.007, 0.011, 0.013, 0.011, 0.005, 0.012, 0.011, 0.006, 0.012, 0.013]
closed: left
isdensity: false

groups is the name of the group to read, "pdf/mul_surv" by default. A vector of names reads several groups, which are summed before the division. n_prim_field is the name of the field with the number of primaries. With n_prim_field = nothing the histogram is not divided, and the result is the same as from read_hist.

# sum two groups, then divide by the number of primaries
pdf = read_pdf(file; groups = ["pdf/mul_surv", "pdf/mul_other"])

Weighting the groups

weights gives one factor for each group, for example the fraction of the decays in each component. The groups are multiplied by their weight before they are summed:

pdf = read_pdf(file; groups = ["pdf/mul_surv", "pdf/mul_other"], weights = [0.7, 0.3])
StatsBase.Histogram{Float64, 1, Tuple{StepRangeLen{Float64, Base.TwicePrecision{Float64}, Base.TwicePrecision{Float64}, Int64}}}
edges:
  0.0:10.0:1000.0
weights: [0.2301, 0.2782, 0.286, 0.2677999999999999, 0.27559999999999996, 0.2899, 0.2704, 0.2782, 0.27429999999999993, 0.30679999999999996  …  0.0091, 0.014299999999999998, 0.0169, 0.014299999999999998, 0.0065, 0.015599999999999998, 0.014299999999999998, 0.007799999999999999, 0.015599999999999998, 0.0169]
closed: left
isdensity: false

Any other factor can be applied to the result, which is a normal Histogram. For example, to divide by 2 in place:

pdf.weights ./= 2

The same source in several files

A source is often simulated once per detector type. read_pdf takes a dictionary from file name to weight, for example the mass of each detector type, and returns the weighted average of the spectra. The weights are divided by their sum, and each file is divided by its own number of primaries.

files = Dict(
    "icpc_bulk_2vbb-tier_pdf.lh5" => 87.1,  # detector mass in kg
    "bege_bulk_2vbb-tier_pdf.lh5" => 19.1,
)
pdf = read_pdf(files; groups = "pdf/mul_surv")
